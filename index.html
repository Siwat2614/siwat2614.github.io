01 / FULL STACK

AUNQA-PS-DEMO — ระบบรวม Import, Monitor & Generator

ระบบต้นแบบสนับสนุนการประเมินคุณภาพหลักสูตร AUN-QA รวมการนำเข้าเอกสาร ตรวจความพร้อมหลักฐาน PS และสร้างร่าง SAR ไว้ในเว็บเดียว

  • เชื่อม Import, Monitor และ Generator ผ่าน React Portal และ Nginx Gateway โดยใช้ FastAPI, MongoDB และ ChromaDB
  • ตรวจหลักฐานด้วยสถานะ PASS / FAIL / REVIEW / N/A และอนุญาตสร้างร่างเมื่อ Monitor เป็น READY พร้อมประวัติและแหล่งอ้างอิง
  • บทบาทหลักของฉันคือพัฒนา PS Monitor สำหรับตรวจความพร้อมของหลักฐาน แสดงสถานะ PASS / FAIL / REVIEW / N/A และข้อมูลที่ยังขาดผ่าน Dashboard พร้อมมีส่วนร่วมในการวางแผน ประสานงาน และเชื่อม Monitor เข้ากับระบบ Import และ Generator ของทีม

02 / IOT · MONITORING

Weather & Air Quality IoT

ระบบติดตามอุณหภูมิ ความชื้น และ PM2.5 พร้อมข้อมูลย้อนหลังและกราฟรายเดือน เชื่อม MQTT → MongoDB → FastAPI → Dashboard
